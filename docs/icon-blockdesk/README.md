# BlockDesk 启动器图标（最终版）

图标采用用户提供的原作（`source-provided.jpg`），仅做了三件技术处理：
按底板边缘精确裁切为正方形、按 22.5% 圆角生成透明遮罩、按尺寸重采样导出。

原始素材右下角的生成水印位于底板之外，裁切后已完全不在成品中。

## 文件

| 文件 | 用途 |
|---|---|
| `blockdesk-icon-dark-1024.png` | 主图标（1024×1024，圆角透明） |
| `blockdesk-icon-dark-{512,256,128,64,48,32,24,16}.png` | 各尺寸 |
| `BlockDesk.ico` | Windows 多尺寸图标（256/128/64/48/32/24/16），已作为启动器 exe 图标 |
| `blockdesk-icon-preview-dark.png` | 尺寸对比预览 |
| `source-provided.jpg` | 用户提供的原始图，留档 |

## 处理参数

- 底板实测范围：x 170–853，y 154–877（1024×1024 原图）
- 裁切：以底板中心取 684×684 正方形
- 圆角：半径 230px（22.5%），输出带 alpha 通道
- 重采样：Lanczos；16/24/32 由 1024 直接缩小，避免多次重采样发虚
- 水印：位于底板外（右下角），裁切后不含

## 小尺寸表现

| 尺寸 | 表现 |
|---|---|
| 128+ | 完整可读：青色光环 + 绿色方块 + 中央像素立方 |
| 64 | 光环保留，方块细节化为色块 |
| 32 | 读作"青绿发光体的深色方块图标"；细节不可辨属正常（原图细节密度高） |
| 16 | 建议仅在 16px 场景使用同时提供的简化标记，或接受为色块 |

## 使用

- Windows 可执行文件图标：`BlockDesk.ico`（已接入 `src/Orion.App/Assets/app.ico`）
- 网页 / 关于窗口 / 商店页：`blockdesk-icon-dark-512.png`
- 需要更大或更小尺寸：从 1024 用 Lanczos 缩放到目标尺寸，单次缩放即可
